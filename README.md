NEON HARBOR is a round-based tactical FPS set in a dusk-lit container dock. Dock Raiders vs Harbor Guard fight across three lanes: plant the charge at Site A or Site B, or eliminate the other team. Earn money each round and spend it in the buy menu on rifles, SMGs, shotguns, armour and grenades — then face bots that push sites, hold angles, and rotate on sound. Runs offline from static files, single-player against bots, built with three.js 0.187.0.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
